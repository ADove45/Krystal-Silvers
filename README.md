# Krystal Silvers

Mafia Romance interactive stories, hosted on GitHub Pages. No build step.

- `index.html` – author landing page
- `good-girl.html` – *Mafia Daddy's Captivating Good Girl*, a self-contained interactive romance (5 acts, 6 endings, HER/HIM scenes, Listen). Set `CONFIG.BOOK_URL` at the top of its script to show a "Read the full novel" button.

## Publish
Repo Settings → Pages → Deploy from branch → `main` and `/ (root)`.
